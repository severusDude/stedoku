## Overview

Stedoku provides a distraction-free environment for playing and solving 9x9 Sudoku puzzles. With instant backtracking validation and tactile keyboard navigation, it offers an engaging experience for puzzle enthusiasts.

## Highlights

- **Instant Constraint Validation**: Real-time checking of row, column, and 3x3 block conflicts.
- **Clean Minimal Design**: Focused monochrome and high-contrast color schemes for visual clarity.
- **Keyboard & Touch Controls**: Seamless cell selection via arrow keys, number pads, or touch gestures.

## Local Setup

```bash
git clone https://github.com/severusDude/stedoku.git
cd stedoku
npm install
npm run dev
```
